# Revision 030：原始训练对齐与报告口径修正

## 任务边界

本版本是只读重分析和报告修正，不是新训练实验。依据用户“不要更改原始训练”的要求，主比较明确绑定 Revision_028 已冻结的 seed=17 原基础模型与原全层模型。不会为了已知测试分数改变训练、选种子、选层、选 k 或隐藏负结果。

所有新文件只写本代码目录及 `Outputs/Experiments/Hourly_Attenuation_Revision_030_Original_Training_Aligned`。原始 H5、ERA5、数据集、旧版本代码、模型、预测、QA、图表、报告以及慢变/快变冻结包均只读。程序不导入训练模块、不反序列化模型、不调用 fit/predict、不读取原始测量样本。

## 必须分开的两种比较

1. **原主模型比较**：Rev028 基础 50 列，seed17，46 轮，天气加权、门控融合、dropout=0.3、weight_decay=0.01；对比 Rev028 全层 156 列，seed17，53 轮，统一权重、无门控、dropout=0.2、weight_decay=0.001。两输入池各用相同候选预算、同一验证目标独立确定配置。此比较回答两个完整建模方案的性能，不是仅改变特征、其他超参数完全相同的消融。
2. **固定全层配置的特征分析**：Rev029 的全部 1024 层组合和 156→1 列 RFE 均使用 Rev028 全层的 53 轮配置。其 mask0 是另行从头训练的“基础 50 列、统一 53 轮”模型，不是原基础 46 轮模型。它的雨天结果和其他负结果必须原样保留，不得用原基础 46 轮替换 mask0、改变层贡献配对或 RFE 路径。

原全层 53 轮模型是两项分析的共同锚点；核对 mask1023、RFE k156 与该锚点的逐小时预测和特征名单完全一致。Rev029 训练内 one-SE mask64/k5、5120 个层配对、自然删除路径和原独立 QA 全部不变。

## 统计与论文表达

RMSE/MAE/Bias 均按对应天气的小时汇总，Bias 是预测减实测的均值。测试集仍是原 687 小时，雨天统一包含全部雨天；不改变样本或阈值。历史测试访问、测试日期与训练日期重叠仍保留，不称新盲测。

不在本版本新增显著性检验或置信区间。原三种子区间不能当作 seed17 的区间；Rev029 同配置配对区间不能移植到 Rev028 基础46轮的比较。原区间仅作为各自设计的只读附件保留。

最终报告不得声称所有训练设置下加层必然改善、所有天气均有显著改善，或 RFE 小模型已经保留全层精度。报告调整完成，不等于得到新的改善模型。
