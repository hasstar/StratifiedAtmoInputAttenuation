## 数据与模型

仍用Signal_Detectability_Revision_003的2404训练、343验证、687测试小时。目标为相对晴空衰减clear_sky_attenuation_db。保留Rev023冻结的156列：50基础列和106气压面列；基础列包含柱积分参数，不能全部称为纯地面参数。天气标记只用于统计，不是输入，也不决定RFE删除。

统一沿用Rev028全层seed17的配置：BiLSTM、53轮、AdamW、学习率0.001、dropout0.2、weight_decay0.001、批量128、统一样本权重、无门控融合。每次从头初始化模型、训练期中位数填补及z-score；目标均值/标准差只由该次拟合行计算。343验证小时已经在Rev028用于选定53轮；本版不为各状态重新选轮，不用测试回调参数。

沿用纵向结构：基础分支188个原始布局槽位，实际变量仅来自保留的基础列；每个仍有变量的气压面以16个布局槽位为token。非保留槽位是无信息的结构填充，不是本次实验的输入变量。完全删除的气压面不进入BiLSTM序列。每次删除后重新拟合，不能解释为对既有模型仅置零推理。气压面不是相邻小时；BiLSTM沿同一小时的垂直气压面序列工作。

## 训练内日期折

采用GroupKFold(3)，group为训练小时的北京时间日期；同一天不能同时出现在该折拟合/检查端，2404个训练小时各作一次折外检查。此处三个折仍全部用seed17，不是三个随机种子。每状态有3个训练内折模型及1个完整训练集正式模型，共4次53轮拟合。训练内曲线用于透明记录，不改变冻结的53轮。官方验证/测试数据不进入这些拟合。

## 分层实验

十层顺序为925、850、700、650、500、300、200、30、5、1 hPa，mask第i位表示是否使用第i层。每个mask保留全部50基础列与所选层的筛后列，重新训练，1024状态、4096次拟合、1024正式模型及3072折模型。mask0也是53轮、统一权重的重训基线；不能拿Rev028独立调参的46轮加权基础模型混作此处对照。mask1023必须复现Rev028全层seed17训练预测和权重，最终评价时核对原验证/测试预测。

每层在其余九层相同的512个上下文中做成对比较。报告RMSE(不含该层)−RMSE(含该层)的均值、中位数和正值比例，分别给总体/晴天/雨天/干燥阴天/其他天气，并保留全部5120个层配对。正值表示该上下文中误差下降；这些是模型的统计增量，不是物理因果贡献。

## RFE

独立从156列开始，不能接在某个测试最优mask之后。每状态重训3个训练内折模型和1个正式模型。BiLSTM没有树的gain，所以采用折外置换重要性：每列在每折检查行中独立打乱一次，重要性=打乱后总体RMSE−原总体RMSE；三个折等权平均，删除最小列，精确并列按完整列名排序。置换种子由冻结指纹、k、折编号、列名SHA256确定，与模型种子17不同。每次只删1列，直到1列。无分层配额、无强制前10包含某层、无固定最终k。156状态、624次拟合、156正式模型、468折模型、155次删除、36735次折外列置换评价。

## 选择与最终评价

两条训练路径全部完成、独立训练QA PASS之后，先冻结各自训练内one-SE描述性方案：最低三折平均RMSE+该状态折间SD/√3以内，层路径取最少层，RFE取最少列，随后按训练内分数和mask解并列。one-SE是简约选择启发式，不把三折当独立重复来声称显著性。最终测试曲线仅描述，不按测试结果挑层或k。

随后仅加载保存模型，在343验证和687测试小时评分，零次拟合。每状态保存逐小时预测、完整列名、RMSE/MAE/Bias；Bias是预测−实测的平均。五个分组为总体、晴天、雨天(合并全部雨)、干燥阴天、其他天气。正式指标以单个seed17模型计算，不平均随机种子或集成预测。

对预定全层/基础、训练内选定/基础、全层逐层删除对照及RFE训练内选定/全列，计算按日期成对bootstrap区间。每个天气的有效日期为重采样单元，日期内小时一起重采样，保持RMSE的小时权重。4096次、固定bootstrap种子20261012，95%百分位区间；不做测试驱动筛选或逐层显著性宣传。所有层的512上下文分散不是独立样本量512。
