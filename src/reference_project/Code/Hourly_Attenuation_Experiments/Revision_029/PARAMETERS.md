# 参数：why / how / source

|参数|值|为什么 / 怎么来 / 来源|
|---|---|---|
|唯一模型种子|17|我明确不做三种子平均；沿用Rev028默认种子，不根据本轮结果挑种子|
|学习器|BiLSTM纵向剖面|我指定当前53轮模型；结构继承Rev014/Rev028|
|正式训练轮数|53|Rev028全层验证搜索选定；本版所有状态同预算，不重新早停，不采用46轮基础或62轮旧版|
|学习率/dropout/weight_decay|0.001/0.2/0.001|完整沿用Rev028全层choice，不重新调参|
|优化器/批量/CPU线程|AdamW/128/2|复现Rev028冻结训练器，避免并行线程差异|
|样本权重/门控|uniform/False|53轮获选全层配置；不是把更有利的另一配置拼进本轮|
|中位数、z-score、目标均值/标准差|每次拟合行估计|折外、验证、测试不参与估计，缺失/无信息槽位保留结构布局|
|特征池|156=50基础+106压力|Rev023训练期物理筛查和去相关的冻结名单，不再筛到期待答案|
|气压面|925/850/700/650/500/300/200/30/5/1 hPa|冻结原始布局顺序；没有配额或预定有用层|
|1024状态|2^10|全部压力面组合；每状态含50基础列并重新训练|
|训练内折|3个GroupKFold日期折|保留先前4次拟合/状态预算，以完整日期分组；所有训练小时恰作一次检查；不同于三种子|
|RFE删除|最小折外置换ΔRMSE|仅训练内总体RMSE，自然删除1列，负重要性保留原值；不看天气或官方验证测试删列|
|置换次数|每列每折1次|沿用旧BiLSTM RFE预算；确定性SHA派生打乱，不测试选择次数|
|置换并列|完整列名字典序|可重复解并列，不偏向压力列|
|one-SE|最低CV均值+SD/√3|固定的简约启发式，训练内冻结；不是独立重复的置信区间|
|bootstrap|4096次、seed20261012、日期成对、95%百分位|沿用4096精度预算，日期内小时不伪作独立重复；只对协议预定对照给区间|
|测试天气数|687/322/51/158/156|冻结数据集的总体/晴天/雨天/干燥阴天/其他天气；只在最终评价核对|
|比较方向|不含或基础RMSE−含或完整RMSE|正为加入后的误差下降，负为误差增加；不把模型贡献叫物理因果|
|锚点容差|1e-8 dB/权重参数|数值复现的严格验收，不作为允许优化或更换方案的依据|
