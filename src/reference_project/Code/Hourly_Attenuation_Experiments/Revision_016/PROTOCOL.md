# Revision 016 预定协议：ITU 雨衰基线与残差检验

本文件在本版首次训练与查看本版测试预测之前冻结。原始 H5、原 ERA5、Run_011、现有数据集、Revision_015 均只读；新代码和结果仅写 Revision_016。

## 问题、边界和输入

目标是本地小时 `clear_sky_attenuation_db`，沿用质量合格的训练 2404、验证 343、测试 687 小时。雨天含全部强雨，不再单列为主要模型选择目标；干燥阴天和总体也必须报告。Rev015 的 `reference`（全 348 特征浅树均匀权重）与 `winner`（局地 117 特征 profile 配置、适度事件权重）是冻结的旧对照，直接复用其保存的逐小时预测，不改变或重训。

ITU 雨衰输入：论文原稿报告下行 19.13 GHz、卫星名义轨位 125.0°E、地面站约 39.9°N/116.3°E；用户于 2026-09-30 确认整段观测期始终为 19.13 GHz、圆极化。由球形地球 GEO 几何计算仰角；名义轨位和站点近似坐标仍非逐小时星历核准值。主计算按圆极化，水平与垂直极化只是敏感性情景。未知站点海拔不擅自填值：ERA5 `zero_degree_level` 元数据是相对地面的 0°C 层高度，因此在雨高差中直接用 `h_R-h_s = h_0,AGL + 0.36 km`；缺失的 0°C 层高度仅用当前训练折中位数填补，固定训练用全训练集中位数。这个小时 ERA5 层高不是 P.839 的年度平均格点雨高，属于代理。

ERA5 累计降水 `surface__total_precipitation` 的 `t+1` 时间戳对应实测 `[t,t+1)` 小时，转换 `m × 1000 = mm/h`；再扣除同时间戳的累计降雪水当量、下限设 0，形成液态降水率代理。绝不直接拿数据表 `t` 行的累计量充当当前小时。与数据集雨标签逐条交叉核对。缺失的 1 个末端小时降水代理仅置物理基线为 0 并标记不可用，不将其作为可靠物理评估样本；对模型输入的缺失填补只在训练折拟合。这是**小时末回顾性/估计**，`t+1` 累计降水不可能在 `t` 整点预先知道，不能声称整点实时预报。

## 固定方法

1. ITU-R P.838-3：按官方 Gaussian 系数算 19.13 GHz 的 `k`、`alpha`，`gamma_R=kR^alpha` dB/km。用 P.839-4 的 `+0.36 km` 雨高差及 GEO 仰角算几何湿路径 `L_s`，得 `A_838_geom=gamma_R L_s`。这是**ITU 系数 + 几何路径的小时物理代理**，非完整 P.618 长期统计预测。
2. 附带计算 P.618-14 的水平和垂直缩减后有效长度，把同小时 ERA5 雨率代入原来需 1 分钟 `R_0.01` 的位置，得 `A_618_hourly_proxy`。这是刻意偏离标准输入定义的**探索性敏感性**，不得称标准 P.618 的 0.01% 年超越预测。物理基线和混合模型的主要量使用 `A_838_geom`，P.618 代理仅单独报告。
3. 新直接模型与新物理残差模型均沿用两套冻结 XGBoost 结构：`full348 + shallow + uniform` 和 `local117 + profile + event_moderate`。额外给二者**同样**的两列：当前小时对齐降雨量与 `A_838_geom`。直接模型预测目标 y；残差模型预测 `y-A_838_geom`，最终加回基线。除是否采用物理加法分解外，两者样本、输入、树数、权重及预处理完全一致。主圆极化假设固定，不根据测试挑极化。
4. 三个复用的训练日成组折仅用于诊断（与 Rev015 相同）；不依据测试或正式验证改变输入、树数或模型。固定树数：full 900，local 800。逐树训练/折留出或验证曲线必须保存；实际停止原因是预定树数，不因验证集提前停止。训练折或全训练上的中位数填补、物理雨高填补均在当前训练部分估计。正式验证只评估，测试仅在协议和全训练模型固定且 QA 通过后运行一次。

## 比较和结论条件

主指标分别为总体、雨天、干燥阴天 RMSE（同时 MAE、bias、样本数），保存逐小时预测；对雨天误差差值另给按日期分组的配对 bootstrap 95% 区间。直接与残差模型的**同输入同配置配对**最能回答“ITU 物理基线本身是否增益”；旧 Rev015 对照用于研究“增加当前雨量和物理结构的组合是否比旧流程改善”，不能把其差异全归因于 ITU。结果若恶化须原样呈现，不能再改超参数追测试结果。本数据的测试小时在早先实验中已经查看，当前是锁定方案复评，不能称全新盲测；逐小时随机划分也不能证明跨天气过程泛化。

正式物理局限：地面小时 ERA5 降雨不等于沿斜路径雨场、也不等于 1 分钟强雨率；局部设备变化、湿天线、云和水汽也影响实测相对晴空衰减。因此物理基线不保证点时误差下降；本任务检验的是数据中是否有可量化增益，不预先承诺结果。
