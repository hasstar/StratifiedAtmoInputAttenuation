# Revision 018：训练期 0.90 高相关去冗余及十层实验

本协议在本版正式模型拟合前冻结。上一版用 `|Spearman rho|≥0.95` 作为冗余边阈值，保留 232 列，其中仍有 44 对处于 `0.90<|rho|<0.95`。本版中，我把冗余阈值改为 `|rho|≥0.90`，其余数据、十模型、验证集选模规则及十层残差对照保持一致，避免把多个变化混在一起。

## 数据与筛选边界

- 数据源只读：`Outputs/Datasets/Signal_Detectability_Revision_003`。目标 `clear_sky_attenuation_db`；训练 2404、验证 343、测试 687 小时。仅同小时 ERA5 的 348 个气象列可作输入。时间键、天气事件、质量列、历史功率和目标派生量不作输入。
- 仅读取**训练集的气象列**完成筛选。先删除训练缺失率 >50% 或非缺失唯一值数 ≤1 的列；对其余列计算成对 Spearman 相关，至少 200 个共同有效小时。按缺失率升序、原始列序打破平局，构造高相关图的确定性贪心独立集：若候选与任一已保留列满足 `|rho|≥0.90`，删除候选并记录代表列及相关系数。
- 必须保存原始 348 列、保留列、每列去留原因、全部高相关对、每层保留数、源文件 SHA-256 和筛选指纹。若某个气压面被完全筛空或任何保留列对仍满足 `|rho|≥0.90`，停止而非临时改阈值。本方法去除两两**单调相关冗余**，不宣称各变量完全统计独立或消除了非单调依赖。
- 对 10 个模型，筛除列均不提供观测信息。平面模型实际输入筛后列；保持固定垂直结构的 Transformer、GCN、BiLSTM 使用原 188＋10×16 槽位，但筛除槽位经训练折填补/标准化成为中性零常数。中位数和标准化参数均只用每个拟合折的训练小时估计。

## 十模型选择

复用 Revision 014 冻结的 Elastic Net、RBF-SVR、Random Forest、XGBoost、LightGBM、CatBoost、MLP、垂直 Transformer、GCN、垂直 BiLSTM。每类 4 套既定候选，配置用训练小时拟合，在 343 验证小时逐轮选总体 RMSE 最低的最早轮；最佳配置以固定轮数按种子 17、29、43 重训。保留参数、轮次曲线、结束原因、逐小时验证预测、总体与雨天（含强雨）和干燥阴天指标、单条端到端推理延迟。

模型主排名沿用验证总体 RMSE 和对数单条推理延迟分别 min-max 归一化、50%＋50% 等权，越低越好；另报告纯 RMSE 名次。验证集用于选配置和模型，不被称为独立测试成绩；测试集不进入模型选择。十模型 40 候选、30 三种子验证拟合和独立 QA 完整通过后才能进入分层。

## 十气压面 1024 组对照

固定获胜学习器家族、配置及轮数。筛后的基础列拟合基础模型；用训练自然日分组的折外基础预测构造残差。每个气压面掩码只用该层**筛后保留**的气象列重新训练同容量的 XGBoost 残差头，训练内部三折选择树数及 `alpha∈{0,0.25,0.5,0.75,1}`。空掩码为基础对照，未选层不通过“置零后直接推理”冒充重新训练。

保存全部 1024 掩码的精确特征名单、参数、逐轮曲线、训练内部得分、343 小时验证预测和各天气指标。每层在其余九层的 512 个搭配里作配对有/无层比较，合计 5120 对；搭配相关，不能当独立重复。最终掩码仅按训练内部汇总 RMSE 最小确定，同分优先较少层数和较小掩码；验证集用于过拟合诊断与层贡献报告。全部 1024 结果及独立 QA PASS 后，才计算一次预定 687 小时测试预测和指标，不利用测试回选任何选择。

测试集曾用于历史实验，Revision 017 还只读查看过其标签分布和事件计数，因此本版测试不能称为全新盲测；随机逐小时划分也不能证明独立跨时段或跨地点泛化。新文件仅存放在 Revision 018 代码目录和 `Outputs/Experiments/Hourly_Attenuation_Revision_018_Correlation_090`；原始 H5、ERA5、Run_011、数据集以及以前全部实验版本保持只读。旧版结果可在新版核验后另行归档或删除，但不是新实验的前提。
