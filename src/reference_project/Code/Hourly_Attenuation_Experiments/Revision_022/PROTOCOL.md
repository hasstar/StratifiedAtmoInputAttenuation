# Revision 022 — unconstrained, event-aware selection of meteorological information

## Question and non-negotiable boundary

Test whether vertical ERA5 information improves same-hour clear-sky-relative attenuation estimation, especially rain and dry-overcast hours, **without requiring any pressure-level variable to survive** and without fixing a desired feature count. The outcome may contain no pressure-level feature. Do not edit or overwrite Revision 018–021 or any source data. The target is `clear_sky_attenuation_db`; event/time/measurement/quality columns are never predictors.

The existing XGBoost family and its frozen configuration (at most 300 histogram trees, depth 5, learning rate 0.03, subsample/column sample 0.8, L2=1, two threads) are used to isolate feature selection. XGBoost was selected using this local test set in earlier work; this run cannot turn the same 687 hours into a new blind holdout. The code in this revision must not read `test.parquet` or its targets until every feature-selection decision, group choice, feature count and final fitting rule is frozen. The test split is the final metric reporting set, not a selection set.

## Inputs and unbiased candidate eligibility

Start from all 348 same-hour ERA5 columns: 188 base and 10 pressure levels ×16. Do **not** reuse the previous 0.90 correlation filter or manually exclude albedo, soil, high layers, or other inconvenient variables. Remove only columns proven all-missing or constant among 2404 training hours. This objective data-quality check uses no target, event, validation or test value. Every other original predictor is eligible. Missing-value imputation is fitted afresh on the fitting rows of each inner fold; no validation/test statistics enter preprocessing.

## Training-only selection and scalar objective

Build three frozen, day-disjoint, weather-stratified folds solely within the 2404 training hours. Rain includes heavy rain. Compare candidates by the equally weighted mean of fold RMSE in (i) all hours, (ii) rain hours, and (iii) dry-overcast hours; all terms have dB units. Equal weighting gives the two review-priority non-clear conditions a voice without including event labels as model inputs. Preserve each constituent metric and sample count. The fixed objective is about prediction conditions, never about whether a feature is surface or pressure-level.

1. **Group stage.** Define 11 non-overlapping, pre-existing information groups: one base group and one group for each of the ten pressure levels. Begin with all eligible groups. At each step, fit each possible one-group deletion candidate afresh in all training-only folds, using validation-fold early stopping; remove the group whose deletion has the smallest cross-fold event-aware score (deterministic tie-break by original group order). Save all candidate predictions, scores, rounds, and full feature names. Continue until one group remains. The smallest candidate group subset whose mean score lies within one standard error of the path minimum is chosen. No group—including base—is mandatory. This is a predictive group-selection rule, not a physical causal estimate.
2. **Column stage.** Independently start from (a) all eligible base columns and (b) the group-stage selected columns. For both, follow an unconstrained path down to one column. At each step fit the currently retained subset afresh in all training-only folds, calculate each column's held-out permutation change in the same event-aware score, and remove the least useful column (ties in original column order). Refit at the next step. Checkpoint every fit, curve, permutation score, and complete feature list. Select the smallest column count within one standard error of that branch's minimum cross-fold score. No feature count is hard-coded and no vertical quota is imposed. If the group branch becomes identical to base, retain and report that empirical result.
3. **Freeze and assessment.** Freeze both selected subsets, both full input-pool baselines, and a same-feature-count comparison using the smaller of the two algorithm-selected counts. Fit three seeds (17,29,43) on the same 2404 training hours; use the 343 validation hours only to choose each model's best boosting round/stop, with its imputer fitted on training only. Then and only then load the 687-hour test split. Save per-hour predictions, full parameters and round curves, overall/rain/dry-overcast metrics and paired day-block uncertainty. Test results cannot alter the paths, feature counts, selected groups or model family.

The external Ku/Ka stations and 100 ms fast component are outside this experiment. Do not claim an effect is significant without an uncertainty analysis. If vertical variables are not selected naturally or do not improve held-out conditions, report that outcome and narrow the paper's claim; never alter a quota or stopping rule after seeing the result.

## Gates

`prepare` freezes source hashes, feature eligibility and training-only folds; `verify-prepare` must PASS. `groups` creates 11 states and all required deletion candidates; `verify-groups` must PASS before any column-stage work. Column-stage QA for both branches precedes freeze. Only after freeze QA PASS may the formal validation/test model be fit/scored. Persist a manifest, stage-specific QA JSON, complete feature lists, per-fold metric and round histories, and a readable final report. Workers are checkpointed; a live matching worker is only inspected, never restarted.
