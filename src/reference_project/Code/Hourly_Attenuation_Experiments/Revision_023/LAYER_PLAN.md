# Frozen direct-refit pressure-layer plan (Revision 023)

This plan is fixed after ten-model QA PASS and before any layer fit. The selected learner is deterministic RBF-SVR. Its four `C`/`epsilon` settings are exactly those in the frozen ten-model manifest; the preprocessing and solver settings remain the same. There are 50 screened base weather columns and 106 screened pressure columns in ten nonempty, naturally retained groups. No pressure level or performance direction is required to win.

Enumerate every mask from 0 to 1023 over pressure levels `925,850,700,650,500,300,200,30,5,1` hPa. A mask's input is always all 50 screened base columns plus all screened columns of its selected levels. This includes base-only and all-ten-level cases. Each mask is **refitted**, never zero-masked and never modeled as a residual head.

For every mask and every one of the four fixed SVR configurations, fit three identical, training-only `GroupShuffleSplit` folds (20% held-out *calendar days*, random seed 20261002). Median imputation and standardization are fit inside the fold. Save each fold's train and held-out RMSE, MAE, rain and dry-overcast metrics, solver iteration and complete hourly held-out predictions for the selected configuration. Select each mask's configuration by mean held-out overall RMSE, then mean MAE, then configuration ID. Using that configuration, refit on all 2404 training hours and save the model, preprocessing, training metrics and solver iteration. For RBF-SVR there is no epoch/early-stop round; convergence is governed by the solver.

Choose a single candidate mask **without validation or test** by the one-standard-error rule: find the lowest three-fold mean overall RMSE; set the threshold to this minimum plus that mask's standard error across folds; among all masks within it choose the one with the fewest pressure groups, then lowest mean RMSE, then smallest mask ID. This prevents selecting an unnecessarily complex mask on a tiny fold advantage. The base and full masks are mandatory comparators even when the chosen mask equals either one. For each pressure level report the 512 matched-mask differences in training-fold RMSE, where positive `RMSE(without)-RMSE(with)` means adding that level helped in the given context. These are context-dependent predictive comparisons, not causal atmospheric effects.

The 343-hour validation set is used only for diagnostics of the frozen base/full/one-SE-selected models (there is no SVR training round to stop). It does not choose the mask. After all 1024 subset files, model artifacts, and independent QA PASS, open the previously accessed 687-hour test partition in one batch scoring stage. Score each already-fitted mask once, save overall/rain/dry-overcast and per-hour predictions, and mark the 1024-mask test sweep exploratory. Do not use test rankings to change a configuration, mask, model or claim. The confirmatory comparison is base versus full and base versus the training-selected mask, with paired day-block bootstrap intervals; include the same-day train/test overlap limitation. The test has historical access and is not a fresh blind or unseen-day test.
