# Revision 014：自包含复跑，正式验证集选轮与模型，测试只作最终复核

本协议在 Revision 014 的首次拟合前冻结。此版把所需模型定义和数据加载函数放入当前代码目录，在相同数据和规则下复跑，以便清理旧实验后仍能独立复核。只用 `Signal_Detectability_Revision_003`：训练 2404、验证 343、测试 687 个质量合格小时。标签为同小时相对晴空衰减 `clear_sky_attenuation_db`（dB），十模型共同输入 348 个同小时 ERA5 特征，其中 188 个基础局地/近地面/整层变量和十个气压面各 16 个变量。基础 188 不是纯地表。事件、时间键、质量、目标派生量、历史功率绝不作输入。只在各自拟合小时计算中位数填补和需要的标准化。

## 十模型正式训练方案

Elastic Net、RBF-SVR、Random Forest、XGBoost、LightGBM、CatBoost、MLP、垂直 Transformer、垂直 GCN、垂直 BiLSTM 的结构及各 4 组候选参数定义在本目录 `models.py`；本版全部重新拟合，不继承历史排名或预测。每类配置先固定随机种子 17 在全部 2404 训练小时拟合，在正式 343 验证小时**逐轮**记录 RMSE（可定义轮次的模型）；每组配置选择验证 RMSE 最小的**最早**轮次。四配置按该最佳轮的验证总体 RMSE、再 MAE、再编号选择。该流程承认验证集承担调参与决定停止轮次的职责；因此验证分数不当作无选择偏差的泛化分数。

对胜出的配置，按其选出的轮数，在相同训练小时以 17、29、43 三个种子从头拟合，正式验证重新评分并测单条推理延迟。轮次定义：提升树为累计树，随机森林为累计树，神经网络为 epoch。为保存完整曲线，候选配置先训练到预设上限，之后提取最佳轮，再以最佳轮数重训；这属于**验证选轮后定长重训**，不能写成节约计算的真实 early stopping。随机森林的每棵树累计曲线亦如此。Elastic Net、SVR 是一次求解器拟合，没有同义 epoch/树轮，保存其求解器迭代数、终止方式和最终训练/验证指标，不伪造逐轮曲线。所有模型和每套配置保存完整参数、训练/验证逐轮 RMSE、候选最佳轮、正式结束轮、选择原因、完整验证预测。

主模型按此前约定：十模型三种子平均验证总体 RMSE 与已训练模型的单条端到端推理延迟各占 50%；前者 min-max 归一化，后者取对数后 min-max 归一化，分数越小越好。单条延迟：填补→标准化（若需要）→模型→输出，预热 20 次，100 个固定验证输入各测 3 次，种子取 300 次中位数，家族取三个种子中位数的中位数。并列先看原始 RMSE、雨/强雨/干燥阴天 RMSE 平均、模型名；同步给纯 RMSE 排名及精度权重 25%/75% 敏感性。天气条件只作报告，不改变主规则。此处**完全不读测试预测或误差**。

## 1024 个气压面组合：基础＋分层残差

胜出模型家族、配置和正式轮数固定后，用它训练 Base188。为给残差头产生较可信的训练目标，在每个拟合子集内按北京时区自然日做 5 折 GroupKFold，基础模型对留出日的预测组成训练折外残差 `真实衰减−折外基础预测`。每种非空层组合各自从头训练一台容量相同的 XGBoost 残差头；只输入该组合的 16×层数个分层变量，不输入基础参数、事件或时间。残差头上限 120 棵、深度 2、学习率 0.03、min_child_weight 10、L2 5、行/列抽样 0.8、种子 17、2 线程。Base188 不随组合变化；缓存其确定性拟合与折外预测等价于每组重复做同一基础拟合，不把未选层置零。

每组组合在正式训练集内部采用固定的 3 次**按自然日成组随机留出**（GroupShuffleSplit，留出约 20% 日期，种子 20260930），每次重新构造基础折外残差并训练该组合残差头到最多 120 棵，记录每棵树的拟合/组外残差目标 RMSE。每次选组外 RMSE 最小的最早一轮，三次最佳树数取中位数作为该组合的正式树数。残差强度 `α∈{0,0.25,0.5,0.75,1}` 按三个训练内部留出结果合并后的最终衰减 RMSE 选，平局选较小 α。然后在全部 2404 训练小时重算按天折外基础残差，并以该组合正式树数**从头训练**残差头；正式验证 343 小时报告 `Base188+α×残差头` 的逐小时预测及总体/各天气指标。空组合是第 1024 种 Base188 对照。所有组合存完整特征清单、3 次组外逐轮曲线、α 候选分数、实际正式轮数、停止依据与训练逐轮曲线。

主组合只按**训练内部** pooled RMSE 选，平局选层数少、再选掩码小。验证集不因 1024 次扫描而被再次用来挑掩码；它用于判断训练内所选组合是否过拟合，并报告层贡献。某层贡献是在其余九层固定的 512 种搭配中，比较加入/不加入该层后的验证 RMSE 差，同时报告雨、强雨、干燥阴天。512 种搭配高度相关，不作独立样本显著性检验。总共 1024 组、5120 配对必须完整核验；不把部分结果叫完成。

## 最终测试与解释边界

十模型与组合均锁定、独立 QA 为 PASS 后，测试集只用于一次固定方案复核：胜出模型的 Direct348、残差 Base188、训练内部选出的层组合、全十层残差四个预定对照。报告总体和晴朗干燥、雨（含强雨）、强雨、干燥阴天、雪（仅个案）、>5 dB 深衰落的 n、RMSE、MAE、bias，不根据测试改变模型、轮数、α、层组合或主结论。原 H5、ERA5、Run_011 和数据集保持只读；本版只写论文工作区 Revision 014。

逐小时随机划分可能让相邻小时或同一场天气过程同时出现在不同集合；且本地测试集在早期实验中已被查看/评分，无法重新称为完全新盲测。本版遵守测试不反向调参，但测试只是一项固定方案复核，不是异站或独立跨时段泛化证明。
