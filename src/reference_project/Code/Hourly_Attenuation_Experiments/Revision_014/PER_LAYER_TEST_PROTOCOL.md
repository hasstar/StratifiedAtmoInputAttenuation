# Revision 014 补充实验：1024 组逐层重训与测试集评价

本协议在补充实验首次训练前冻结，不修改原 `PROTOCOL.md`、十模型选择、原 1024 组训练/验证结果或四方案正式测试。补充输出只写入本版实验目录的 `layers/heldout_all_masks/`。原 H5、ERA5、Run_011、所有数据集和原实验结果只读。

## 输入与锁定参数

- 标签：同小时相对晴空衰减 `clear_sky_attenuation_db`（dB）。2404 个训练小时、343 个验证小时、687 个测试小时，348 个同小时 ERA5 特征。时间、事件、质量、历史功率和目标派生量均不输入模型。
- 学习器固定为既有十模型比较选出的 XGBoost；Base188 用原先锁定的深度 5、学习率 0.05、499 棵树、种子 17。补充实验不重新选模型。
- 1024 个分层组合的残差头统一为深度 2、学习率 0.03、其余配置见 `common.py` 的 `RESIDUAL_CONFIG`。每个组合的正式树数和残差系数 α 只取自先前**训练集内部按自然日分组留出**所得记录；制订训练计划时重新核对 α 是训练内部候选分数的最小值，树数是三次训练内部最优轮数的中位数。绝不以验证或测试误差改动这些参数。

## 阶段门槛与数据隔离

1. `plan` 只读训练集、特征字典、冻结的十模型选择以及原组合记录中的训练内部字段，生成不含验证/测试预测或指标的独立训练计划。此阶段不读 `validation.parquet`、`test.parquet`。
2. `train` 只读 `train.parquet` 和训练计划。先重新拟合 Base188，并以训练集内部按日 5 折的折外基础预测建立残差目标；再将 1023 个非空组合的残差模型**逐个从头拟合**，包括最终 α=0 的组合。各模型的缺失填补中位数仅由训练小时计算。每个模型、填补参数、特征名、α、树数和训练曲线均保存。空组合是重新拟合的 Base188。1024 种方案及模型文件全部核验、写入训练锁定记录后，不再拟合或调参。
3. `validation` 仅在训练锁定后读取验证集，计算所有方案的验证误差作为过拟合诊断；不选择组合或修改训练参数。验证完整性检查通过后才允许下一阶段。
4. `test` 才读取测试集，一次性为全部 1024 种已锁定的方案生成逐小时预测、总体和天气事件 RMSE/MAE/bias。测试指标不用于回头选模型、选层、选轮次或调整 α。测试阶段完成后，`train` 命令拒绝再次执行。
5. `report` 和独立 QA 复算 1024 方案、每层 512 种其他层搭配（共 5120 对）的测试差值。正差值定义为“不含此层 RMSE − 含此层 RMSE”，即正数表示加该层误差降低。另报告只加一层相对于空组合的测试指标。

天气事件只用于分组评价：晴朗干燥、雨（含强雨）、强雨、干燥阴天、雪和 >5 dB 深衰落；雪样本很少，仅作描述。512 个搭配共享测试小时、彼此相关，不能当作 512 次独立复现。此补充实验保证**本轮代码的数据隔离与不以测试调参**；本地测试小时在历史实验中已被查看，故不称全新独立盲测。
