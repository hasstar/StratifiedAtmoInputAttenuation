# Revision 017：训练期相关性去冗余 → 十模型比较 → 十层组合

本协议在本版首次模型拟合前冻结。目的不是保证统计意义上的完全独立，而是在不借助目标值选列的前提下削减明显重复的 ERA5 信息，然后检验模型选择及垂直层结贡献。新结果独立保存在 `Outputs/Experiments/Hourly_Attenuation_Revision_017_Correlation_Pruned`，数据集、原始 H5、ERA5、Run_011 以及 Revision 014–016 均只读。

## 数据与特征工程

- 正式目标：同小时 `clear_sky_attenuation_db`；训练 2404、正式验证 343、预留测试 687 个质量合格小时。348 个候选输入仅为同小时 ERA5 大气列；时间键、事件标签、质量列、历史功率和目标派生值不作输入。
- 特征筛选**只读取训练集气象列**，不读取验证/测试气象值或任何衰减标签。训练期缺失率 >50% 或非缺失唯一值数 ≤1 的列先剔除。对剩余列计算成对 Spearman 相关，至少 200 个共同非缺失小时，若 `|rho| ≥ 0.95` 则视为冗余边。按训练期缺失率从低到高、同分按原始列顺序贪心保留；遇到与任何已保留列有冗余边的候选即剔除。输出每列去留原因、相应代表列、系数、完整保留名单、相关矩阵检查及源文件 SHA-256。原始列顺序决定实际模型输入顺序。
- 该阈值只界定**两两秩相关冗余**；不宣称保留列统计独立，也不排除非单调依赖。若任一气压面无保留列，阶段门槛失败，须新版本重定规则，不能临时修改本版。用户指定的十层组合仅在本版留下的气压面变量上解释。
- 十模型获得完全相同的保留气象信息。平面模型以实际保留列数作为输入；Transformer、GCN 和垂直 BiLSTM 为保持原有 188＋10×16 垂直结构，在筛除槽位上放训练折标准化后的中性零常数，这些槽位不包含观测信息。每个拟合折的中位数填补及标准化仅用该折的拟合小时估计，绝不借用验证/测试小时。

## 十模型公平比较

复用 Revision 014 已冻结的 Elastic Net、RBF-SVR、Random Forest、XGBoost、LightGBM、CatBoost、MLP、垂直 Transformer、GCN、垂直 BiLSTM 定义，每类 4 套既定候选参数，统一种子 17、29、43。候选配置在完整训练集拟合，343 小时验证逐轮选最低总体 RMSE 的最早一轮；选最佳配置后按该轮数以三种子定长重训。完整保存参数、每轮训练/验证 RMSE、结束轮、逐小时预测、总体与雨天（含强雨）及干燥阴天指标、单条端到端推理延迟。验证集既用于调参与选模型，其分数不是无选择偏差的独立测试分数。

沿用 Revision 014 的预定主规则：三种子平均验证总体 RMSE 和单条推理延迟的对数分别 min-max 归一化，等权 50%＋50%，越低越好；同时报告纯 RMSE 排名及 25%/75% 精度权重敏感性。天气事件只作报告，不参与本阶段输入或改变选模规则。40 套候选、30 次三种子验证拟合及独立 QA 完整通过后方可进入分层。正式测试此时不读取。

## 十气压面 1024 组合

固定十模型胜出的学习器家族、参数与轮数，不根据组合结果切换学习器。沿用 Revision 014 的“基础气象预测＋分层残差头”规则：基础部分为保留的基础 188 列（筛除槽位不含信息）；在训练自然日分组的折外基础预测上构造残差；每种气压面组合只用所选气压面中**保留下来的**原始变量，从头训练相同容量的 XGBoost 残差头。内部三次按日留出选树数与 `alpha∈{0,0.25,0.5,0.75,1}`；空组合为基础对照。任何未选层都不通过“置零后直接推理”冒充重新训练。

全部 1024 个掩码保存准确特征名单、训练折/轮次曲线、alpha、验证逐小时预测和总体/雨天/干燥阴天指标。十层各在其余九层固定的 512 个搭配中计算加入前后误差差，合计 5120 对；这些搭配相关，不视为独立重复。主掩码仅以训练内部汇总 RMSE 最低选定，平局选层数更少、掩码编号更小；验证集只作过拟合诊断和层贡献报告。1024 结果与 QA 完整通过后才读取预定测试集，测试不反向挑模型、特征、层或轮数。

当前随机逐小时划分可能将相邻小时/同一天气过程分到不同集合，且测试集曾被历史实验查看，因此本版不能称为“全新盲测”或跨地点泛化。独立跨时段和异站试验另行完成。本实验主报告统一使用“雨天（含强雨）”，不单列强雨作为主选择目标。
