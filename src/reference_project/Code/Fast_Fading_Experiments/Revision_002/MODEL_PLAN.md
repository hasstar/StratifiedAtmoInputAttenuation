# C1 边缘分布比较：拟合前冻结计划

2026-10-06，A/B质量QA和窗口汇总均PASS后记录。本计划仅选择快变**边缘分布**，后续相关生成器另行冻结配置。窗口诊断并未选定15分钟。

## 数据与权重

只读正式2,404个train小时、质量零且至少9/10记录的1 s功率比`Q=P_1s/Pbar_h`。每小时的秒按有效100 ms记录数加权，随后每小时总权重为一。这样兼顾W均值所采用的记录权重和天气样本的小时均衡。保留每小时的`E(Q)`偏离一的诊断，不偷偷重新定义实测`F=-10log10(Q)`。

使用完整有效记录拟合和计算分位数，不用抽取最幸运秒样本。边缘统计可以接收缺口两侧的有效数值；缺口仍不能在时序生成中被视为连续观测。

## 日期折

五折按北京时间完整日期隔离，约80%开发训练日期、20%折内评分日期。五折是可承受的重复拟合预算与训练样本比例的设计选择。按月份、当天是否有rain训练小时、设备期划分日期层；在每层中以种子20261006打乱并轮流分配，层间轮转起点保持折大小均衡。5月14日独立标记过渡日。分配只用日期和天气元数据，不用残差值。先保存每日期折号和SHA256，再拟合。

## 八个候选

四种族分别做global统一参数、hourly_weather条件参数，共八候选。条件类别为clear_dry、dry_overcast、rain、other；rain包含全部强雨，雪等归other。没有强制条件模型胜出的规则。

| 族 | 参数和约束 | 参数如何得到 |
|---|---|---|
| Lognormal Q | log标准差`sigma>0`，`mu=-sigma²/2`，因此E(Q)=1 | 在单位均值约束下最小化训练加权负对数似然；sigma²=2 E[(log Q)²]/(sqrt(1+E[(log Q)²])+1) |
| Gamma Q | shape=`a>0`、scale=`1/a` | 解log(a)-digamma(a)=E[Q-log(Q)-1]，单位均值约束MLE |
| Rician envelope | 包络R=sqrt(Q)，非中心比`b>=0`，scale=`1/sqrt(b²+2)` | 训练加权功率比负对数似然的一维数值最小化；不将b解释成已识别的物理直达/多径比 |
| Empirical Q | 训练加权经验CDF，Q除以训练加权E(Q) | 训练有效观测直接形成经验分布；记录归一化常数；不需要假设解析形状 |

所有族在生成意义上均有单位功率矩。Gamma形状与Rician优化失败保留失败记录，并中止该候选的完整性门槛；不能因为评价分数不好替换族。

## 优化的数值设置

- Gamma的shape在log域求根，区间[-20,30]对应很宽的正形状范围，用于数值括根；如果根不被包住，保存失败。该范围不是传播先验。
- Rician初值尺度`b0=2/sqrt(Var(Q))`来自大b时`Var(Q)≈4/b²`的计算起点；训练期搜索`b0/100`至`100*b0`，限制在[exp(-8),10000]，并独立比较b=0的Rayleigh边界。范围由训练方差与数值稳定性限定。倍数100用于宽范围括极小值，触边必须报告，不默默扩大后追分。
- 标量优化上限100次，log(b)容差1e-5；它控制数值精度，不控制训练早停或科学时间尺度。保存成功状态、迭代次数和搜索边界。
- 极端恒定序列会形成退化分布；解析族若无法定义有效正尺度，明确失败，不添加假造的噪声。

## 评分和自然选择

主评分为dB域CRPS的分位数积分近似：`2 integral_0^1 pinball_tau(F - q_tau) d tau`。用201个等距概率中点`(j+0.5)/201`计算；401点重复积分作为数值敏感性，不用401结果回调族选择。概率中点避免无限尾部分位数。全部实际秒参与每小时的加权评分，利用排序累计和计算，201是积分精度/计算预算选择。

每个候选、每个小时保存CRPS201、CRPS401、实测秒数/记录数、经验功率均值、天气/日期/折号、解析族的dB负对数评分和全部201点实际CDF校准值。经验族没有连续密度，不与解析族拼接比较对数评分。

八候选主排序：先每日期平均该日小时CRPS201，再对全部训练评分日期平均；值越小越好。总体主评分确定边缘分布方案；每种天气分别报告，不人为增加雨天评分权重。精确同分时按候选固定名字排序，不挑种子。日期分块给差异区间，连续日期块敏感性仍需在动态阶段落实。

五折完整（40候选-折记录、每小时恰好一次折外评分）并通过QA后冻结获胜族/条件方式，再在全部2,404训练小时拟合最终边缘参数。343验证和687测试小时只在后续所有动态规则冻结后评分。

## 与时间尺度和生成器的关系

边缘族不会给出局部平稳窗。独立抽样是后续时序生成的比较基线；相关序列生成需依据ACF、持续时间、间隔和斜率的日期隔离评分选择相关参数。二者都使用已经冻结的功率比归一化规则。动态模型的具体预算、阈值和块长度选择另在`DYNAMICS_PLAN.md`中登记后运行。

## 文献与实现依据

- 概率预测评分依据：[Gneiting and Raftery (2007), Strictly Proper Scoring Rules, Prediction, and Estimation, JASA 102, 359–378](https://doi.org/10.1198/016214506000001437)。本实验采用损失方向（越小越好）的CRPS分位数积分；201/401的网格数属于数值近似设置。
- 包络参数的实现核对：[SciPy 1.13.1 Rice文档](https://docs.scipy.org/doc/scipy-1.13.1/reference/generated/scipy.stats.rice.html)与[非中心chi-square文档](https://docs.scipy.org/doc/scipy-1.13.1/reference/generated/scipy.stats.ncx2.html)。单位功率Rice的平方变量对应df=2、nc=b²的非中心chi-square除以b²+2。
- 概率质量、单位功率矩和评分公式已用独立数值积分/已知权重例子检查。完整CV的QA还会从原始源小时的逐点pinball损失复算每个候选-折一个小时（40小时核对），避免只相信累计和实现。
