## 窗口端点与质量规则

读取B的全部653,430窗口状态，仍是1/2/5/10/15/30/60 min、四套质量门槛。完全复用原窗口边界、缺秒掩码和有效100 ms记录数权重，不插值。主联合端点为：两半W均值差(dB)、dB标准差差、5/50/95%分位数差和仅相邻有效秒的lag-1相关差，共六个绝对差。B的局部形状Wasserstein保留作独立效应描述，不加入未经登记的混合权重。

每个实际小时生成128条独立3600 s参考序列，使用该小时所属折的训练日期CDF和256 s片段库。对每个有效窗口，模拟与实测使用完全相同的位置掩码/计数权重。相同秒门槛、窗口长度与slot的多个质量状态共享参考统计，避免重复计算。所有生成接缝仍参与端点计算。

## 可重复的联合相容判据

前64条参考序列只估计每端点的参考均值m和标准差s。后64条只用于校准联合量`T=max_j((D_j-m_j)/s_j)`。端点都是“变化幅度”，所以只检查过大的变化，不把更小的漂移判为非平稳。按各端点参考尺度标准化，不将dB与无量纲相关差直接相加；联合最大值保留端点依赖，不作六次独立95%界限判断。

实测T的参考尾概率为`(1 + count(T_cal >= T_obs))/65`；包含并列，永不报零。主窗口判据为尾概率>0.05。0.05是模型诊断容忍比例的工程设置，不是传播物理常数。64条校准的概率分辨率是1/65，必须同时保存原T和全部参考端点，不能仅保存通过/未通过。

前32+后32（分别来自两独立64条银行的前半）重复同一规则，记录分类变化率，作为Monte Carlo敏感性；不按更好看的版本选结论。尺度为零时，端点不超过参考均值记标准化值0，否则为正无穷；端点无定义（如常量序列的相关系数）明确记`incomplete_endpoints`，不假造相关性或自动称通过。所有真实数值失败保存并阻断QA。

该参考尾概率仅在冻结模拟模型条件下解释；模型参数是估计的，不能冒称对未知真实传播过程的精确5%平稳检验。联合模拟参考范围的设计借鉴[Myllymäki等(2017), Global envelope tests for spatial processes, JRSS-B 79:381–404](https://arxiv.org/abs/1307.0239)的同时检查思想，本工程的端点/双银行max-T不是照搬其空间过程算法。

## 汇总与是否支持固定窗口

先每小时统计相容窗口比例，再每完整日期平均，再汇总日期；不把大量窗口当成独立天气样本。报告总体、晴天、雨天（含全部强雨）、干燥阴天及other；全部候选、端点效应、小时/日期数、缺口与无法判定数均保存。

按1/3/7连续日块各2,000次重采样给比例与同日期对照区间，保存可用连续块覆盖；缺日期不能当相邻日。原独立日期折/同日重复观测的统计职责保持不变。

如需给工程固定窗建议，只在训练日期的主质量门槛上自然选择：该天气各较短候选到该长度的日期均衡相容率，其独立日95%区间下界均至少0.90，且64/32双银行版本均满足；取满足条件的最大候选。0.90是明确的工程覆盖要求，补报0.80/0.95敏感性，不伪装成自然常数；如果没有候选满足，保存“无统一固定窗支持”，不强制15 min、256 s或某天气有答案。该建议不改变生成器；最终验证/测试只评价训练期已冻结的规则。
