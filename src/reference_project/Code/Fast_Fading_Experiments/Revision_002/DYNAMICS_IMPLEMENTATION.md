## 精确输出

- `dynamics/folds/fold_0`至`fold_4`：每折四天气CDF的完整离散支持/累计概率、AR系数、小时/日期名单，以及实际连续有效段库。CDF每小时总权重相同，小时内按原始有效记录数加权，承接C1；时间增量每合法秒对等权，不把缺失时间插值成观测。
- `dynamics/r08/trials`：14候选×5折70个状态。每精度级不覆盖其他级，16/32只在精度门槛需要时追加。片段缺乏为无资格；数值/文件错误另存`failures`和原始traceback，不改称无资格。
- `chunks/<候选>__fold_<折>`：每32小时写一次不可变检查点；每小时主/半预算VS；每实现种子、相位、模板来源摘要、功率漂移、各滞后增量/ACF、F分位数、斜率、完整持续时间/间隔列表和删失次数。源小时诊断另存；每折/天气/候选一个可复现序列样例。块来源可由已保存种子和训练段库精确再生成，不上传研究数据。
- `independent_score_audit.csv`、`qa.json`：完整状态数、日期隔离、CDF单位功率矩、真实缺口检查和独立逐点评分复算。正常run结束自动verify，仍需人工先确认进程已结束后读取QA；报告需QA PASS。
- `candidate_ranking.csv`、`weather_scores.csv`、`date_scores.csv`、`hour_scores.csv`、`paired_date_effects.csv`和`DYNAMICS_RESULTS.md`：训练开发期对照。无资格候选不混进排名；其状态仍保存。

## 非科学超参数及数值细节

32小时检查点只是断点恢复粒度，不参与拟合/评分。输出使用float64；整数秒和原始有效记录数保留，不把100 ms动态从1 s曲线推断出来。每实现生成3600秒且用该源小时有效时间位置打掩码评价；真实掩码不依赖候选。生成接缝并不追加掩码。

所有三类生成器在任意时刻具有相同的天气条件边缘分布；片段重排的随机循环相位保证逐时间位置的边缘相同。因此固定滞后的预测期望绝对增量对位置相同，VS可由观测M1/M2和每实现的合法位置平均增量计算；这一步依赖于候选的平稳生成构造，不意味着已证明实测小时平稳。独立QA再按实际每个合法点对展开同一公式。

AR首点为独立标准正态，递推用SciPy lfilter和正确初态，正/负系数都测试。中点PIT按离散CDF全部并列质量的左右端点计算。块库保存半开区间`[start_s, stop_s)`；先均匀选合法训练小时，再均匀选合法起点。最后一块仅取所需长度，但其原始合法起点仍按完整L登记，不借用缺口。

不强制有限实现小时平均Q为1，也不以本地窗口去均值改变F。图表与实际应用需区分源数据的小时W均值恒等式、生成器的总体单位功率矩、有限实现的随机均值漂移。

## 合成数值测试不是论文性能证据

12项用例覆盖离散逆CDF功率矩/中点PIT、完整间隔缺口掩码、连续段端点、AR递推及平稳初态、按小时估计phi、块合法性、秩重排功率样本保持、公共边缘抽样及种子、有限MC交叉平方项、持续时间删失与候选预算。

AR随机数检查用5000条32点实现，均值最大偏差容差0.055、方差0.075；单位功率随机抽样检查用300条3600点实现，容差0.012。这些是可复现程序防错容差，不是实测显著性门槛。功率离散矩另按解析质量直接核对，门槛1e-10来自浮点累计误差容限，不允许以随机样本均值替代该解析QA。
