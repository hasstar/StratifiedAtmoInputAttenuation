## C1拟合前追加

| 参数 | 值 | 为什么/怎么来 | 检查 |
|---|---|---|---|
| 日期CV | 5折 | 约80/20日期训练/评分，可承受重复拟合预算 | 同日期绝不跨折；保存日期清单 |
| 条件数 | global或4小时天气类 | 用同样输入观测检验统一分布与小时天气条件分布 | 不预设天气条件胜出 |
| 正功率族 | lognormal、Gamma、Rician包络、经验CDF | 覆盖常见正功率/包络统计和无解析形状基线；单位功率矩可检查 | 不作成因识别 |
| 主积分网格 | 201等距概率中点 | CRPS分位数积分的计算精度设置 | 同时计算401点误差 |
| Gamma数值范围 | log(shape)∈[-20,30] | 广泛正值括根区间 | 触边/无根记录失败 |
| Rician起点 | 2/sqrt(训练Var(Q)) | Var(Q)≈4/b²的大非中心比近似，用训练方差估计计算起点 | 保存方差与起点 |
| Rician搜索范围 | 起点÷100到起点×100，并限[exp(-8),10000]；加b=0 | 宽括极小值与双精度稳定性限制 | 保存边界/触边；不按最终指标扩范围 |
| 标量优化 | 100次上限，log(b)容差1e-5 | 数值预算与相对参数精度约10 ppm | 收敛状态/次数齐存 |
| 候选选择 | 日期平均CRPS201最小 | 同一评分对象、同一日期的直接概率预测比较 | 天气细分评分与日块差异区间 |

任何新增参数必须先补登记，再运行依赖它的评分。不能以“有文献”替代清楚说明数值究竟来自观测、设计还是估计。
