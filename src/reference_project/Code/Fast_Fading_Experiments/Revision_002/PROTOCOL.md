# 本地链路小时内快变实验：Revision 002

## 1. 实验要回答的问题

小时气象参数已经用于估计小时 W 域平均功率所对应的相对晴空衰减。本阶段研究同一小时内、有效高频观测相对于该小时平均值的偏差，用于提供短时间衰减的概率范围和具有时间相关性的模拟序列。

三个实验分别承担以下职责：

1. **时间尺度实验**：检验窗口前后两半的功率均值、波动幅度、分位数和相关性怎样随窗口长度变化，回答原先“15 分钟”的依据问题。
2. **边缘分布实验**：比较统一分布与按小时天气状态划分的分布，回答是否可以对所有小时使用同一组随机数分布。
3. **时序生成实验**：比较独立抽样与相关序列，检验超越概率、持续时间、间隔、变化速度及自相关，回答模拟的波形是否与实测具有相同的统计行为。

“小时内快变”是这里的操作性名称。只凭功率记录，不能将其全部认定为多径小尺度衰落或对流层闪烁。雨衰在小时内的变化和接收测量波动也可能进入该残差。实验先给出观测统计，再据证据解释成因。

## 2. 定义与功率守恒

以质量合格、已校准的 100 ms 实测功率 `P_t`（W）为基础，沿用冻结的小时标签：

```
Pbar_h = mean_W(P_t in accepted records of hour h)
Abar_h = B - 10 log10(1000 Pbar_h)
A_t    = B - 10 log10(1000 P_t)
F_t    = A_t - Abar_h = -10 log10(Q_t)
Q_t    = P_t / Pbar_h
```

`F_t > 0` 表示比该小时平均功率更低、瞬时衰减更大；`F_t < 0` 表示相对增强。在按有效 100 ms 记录数加权的观测中，`mean(Q_t)=1`。`mean(F_t)` 一般不等于零。每个生成器必须在功率比域归一化，使 `E[10^(-F/10)] = 1`，随后才能与小时慢变结果相加。

局部窗口的半窗均值只用于稳定性诊断。正式 `F_t` 始终相对于小时均值；不以局部去均值替换目标，也不自动增加第三个预测项。

## 3. 数据和统计单位

- 本阶段只使用本地链路。频率为我确认的 19.13 GHz、圆极化。
- 100 ms 质量与小时衰减已经由 Revision 001 独立重算验证。正式 1 s 输入为 `Outputs/Experiments/Fast_Fading_Revision_001/clean_1s/*.parquet`；该数据在 W 域从 `quality_code == 0` 记录重新聚合而来。
- 先验质量审计共 3,434 个有效小时、435 个删失小时。435 个删失小时不赋予精确快变标签。
- 当前时间尺度与模型开发只读取正式 2,404 个训练小时。343 验证小时、687 测试小时不会进入这一轮的窗口、分布和相关长度选择。
- 秒和窗口是同一小时内的重复测量；典型和尾部效应先汇总到小时，再按北京时间日期分块估计不确定性。日期仍可能属于同一持续天气过程，因此后续还需连续日期块的敏感性分析。
- 原小时划分属于随机小时划分。快变模型开发的折必须按完整日期隔离。先冻结日期清单和随机种子，再拟合；最终报告说明小时划分与日期隔离评分各自的用途。

## 4. 参数来源的分类

每个参数必须在 `PARAMETERS.md` 登记为以下类型之一：

1. **测量/既有数据定义**：100 ms、小时 W 均值、质量码、设备更换日期，来自采集与已冻结的数据构建。
2. **文献支持的方法或指标**：分布、时间序列合成、持续时间/斜率、自相关的评价职责有文献依据；文献并不替本数据给出最佳数值。
3. **工程/数值设置**：覆盖率、数值容差、计算预算和随机种子是可复现的设计选择；明确说明理由并做必要敏感性检查，不能伪装成物理常数。
4. **训练数据估计量**：分布参数、相关尺度和方案选择结果由训练日期拟合/交叉验证产生，冻结后才评价验证与测试。

所有阈值均在生成下游评分前登记。原 Revision 001 的汇总曾被查看，因此本轮为其诊断补充，不称预注册或全新盲测。

## 5. 阶段与门槛

### A：已核验窗口汇总的日期分块不确定性

读取 Revision 001 的同小时配对表：七种长度都具备有效窗口的同一批 839 个训练小时、65 个日期。对每种天气输出小时半窗漂移的中位数、90% 分位数及按日期重采样的 95% 区间。2,000 次重采样，同一次抽样同时评价所有长度。主描述对照为雨小时 `30 min - 15 min`；同时保存全部长度和预先列出的 `15-10`、`60-15` 对照。该阶段扩充不确定性，单独不判定平稳窗口。

### B：从秒序列重新做多指标和质量敏感性诊断

窗口长度为 `1, 2, 5, 10, 15, 30, 60` 分钟，窗口位于同一小时内部。每窗口比较两半的 W 功率均值、dB 标准差、5/50/95% 分位数及仅相邻有效秒的 lag-1 相关。记录局部功率归一化后两半的分布距离，区分均值漂移和分布形状改变；此归一化只用于诊断。

同时比较四套质量门槛：9/10 个有效 100 ms 记录的秒、半窗覆盖率 90%、最长缺秒段 5 s；覆盖率提高至 95%；全部秒有效；全部秒均有 10/10 记录。前两套允许的缺口不插值。动态相关和持续时间只在连续有效段内计算。相同长度之间优先使用同小时配对结果，各门槛的纳入数完整保留。

设备更换前后（2026-05-14）及每小时 `k11/k101` 采集配置占比作为测量配置诊断维度，用来识别天气分布差异是否伴随测量配置变化。未经证据不能把配置差异解释为传播机制。

阶段 B 的数值 QA 必须核对时间归属、无跨小时窗口、天气一致、缺口门槛、完整特征与有效值。A、B 均 PASS 后才能进行分布拟合。

### C：日期隔离的分布与相关序列比较

实施前在 `MODEL_PLAN.md` 冻结日期折、分布族、拟合目标、生成器候选、评分以及选择规则。使用小时均衡权重拟合，避免将持续更久的小时直接当成更多独立天气样本。

正功率比分布候选包括均值归一化的 lognormal、Gamma（对应 Nakagami 包络统计）、Rician 包络描述与经验分布基线；统一参数和按小时天气条件参数直接比较。模型拟合失败保留原因，不换一套分布制造通过结果。dB Student-t 的指数功率矩可能不存在，不能未经截断就用作要求平均功率为一的生成器。

用日期隔离评分评价分位数/CRPS或对数评分。动态生成至少包含独立抽样基线和保持连续片段的相关生成器；块长度与相关参数由训练折自然确定。窗口稳定性尺度和生成器的重采样块长度分别记录，不能把两者混作一个“15 分钟参数”。

### D：冻结方案评价和合成

QA PASS 并冻结模型后，评价343验证小时和687测试小时的边缘/动态指标，保存逐小时结果、雨天（含全部强雨）、干燥阴天、晴天及全部样本结果。不以已查看的测试指标回调分布/块长度。

合成 `A_generated(t)=A_slow_predicted(h)+F_generated(t | available hourly weather)`。慢变评价、快变统计评价和合成评价分别给出。12:38 的输出是以小时气象为条件的随机场景或分位数区间。秒级真实天气状态若没有观测，不能凭小时标签补造。

## 6. 方法依据

- [ITU-R P.1853-2：Time series synthesis of tropospheric impairments](https://www.itu.int/rec/R-REC-P.1853-2-201908-I/en)：支持研究时间序列统计和传播分量动态的任务定义；不直接规定本数据的窗口或分布参数。
- [ITU-R P.1623-1：Prediction method of fade dynamics on Earth-space paths](https://www.itu.int/rec/R-REC-P.1623-1-200503-I/en)：持续时间、间隔和衰减斜率的评价动机。其慢变雨衰斜率模型与本实验的小时残差并非相同对象，采用的是指标思想。
- 均值/波动尺度/相关性的稳定性检查属于操作性诊断。仅凭某项检验“不显著”不宣布平稳；最终结论需要效应量、日期分块区间与生成器在未参与拟合日期上的表现共同支持。
