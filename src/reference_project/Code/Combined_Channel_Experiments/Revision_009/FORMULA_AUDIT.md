## 范围与结论

核对用户截图式 (10)–(14)、官方标准的适用量，以及本项目小时相对晴空衰减目标。不是全文审稿，不确认截图的出版身份，也不声称完成 ITU 实现或正式符合性认证。

结论：可以建立含雨、云雾、气体的物理对照；目前旧两条雨衰结果不能换名冒充组合结果。采用截图组合形式之前，需要区分统计分位数与同期物理损耗，并解决输入和晴空参考基准。

## 发现与最小修正

1. **EXTERNAL / MAJOR：概率组合不是小时观测公式。** [P.618-14 §2.5，式65](https://www.itu.int/dms_pubrec/itu-r/rec/p/R-REC-P.618-14-202308-I!!PDF-E.pdf)中的形式为 A_T(p)=A_G(p)+sqrt((A_R(p)+A_C(p))²+A_S(p)²)，各项针对同一超越概率 p，且有概率适用范围。截图把 p 隐去，雨项却使用 R0.01。用于本任务时必须另称“ITU 分量小时近似”，不能称标准年度 P.618 已验证。无合格闪烁输入时，不生成伪完整四分量指标。

2. **EXTERNAL / MAJOR：云量不是云液态水。** [P.840-9 §3.1](https://www.itu.int/dms_pubrec/itu-r/rec/p/R-REC-P.840-9-202308-I!!PDF-E.pdf)提供瞬时柱液态水形式 A_C=K_L(f)L/sin(theta)。同一液态水柱中的云/雾不能重复算两遍；总云量只用于当前天气分组。新版 K_L 不能不经核对直接用旧版实现冒充。修正：补齐并核验 TCLW，不任取云厚或液水密度。

3. **EXTERNAL / DEPENDENCY：气体输入不在现有英国 Top10 中。** [P.676-13 附件2](https://www.itu.int/dms_pubrec/itu-r/rec/p/R-REC-P.676-13-202208-I!!PDF-E.pdf)的近似斜路径方法依赖近地面温度、压强、水汽密度；水汽吸收的另一种方法使用整层水汽。需要固定版本及系数实现核验。最大2米温度不可当作同时刻2米温度，850 hPa相对湿度不可冒充地面水汽密度。

4. **CONSISTENCY / MAJOR：绝对与相对基准不一致。** LOCAL manifest 的 clear_reference_dbm=-76.19362933508154，英国原生标签亦相对晴空。现有证据尚未把该参考映射成各小时/站点的物理气体基线。截图式14的自由空间和馈线项不加到本项目目标；也不直接拿正的绝对气体吸收和相对衰减计算主 RMSE。禁止利用英国标签拟合偏置，禁止重估晴空参考。该映射未落实前组合预测/评分保持未执行。

5. **DERIVED / CAVEAT：小时聚合近似。** 一般 k*(平均R)^alpha 不等于平均(k*R^alpha)。已有小时雨量只能建立小时气象驱动近似，不恢复秒/分钟变化。气体/云/雨分量的可加性本身也不解决接收功率聚合与衰减聚合的差异。
