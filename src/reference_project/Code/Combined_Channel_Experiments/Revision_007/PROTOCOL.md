## 评分定义（在首次交付前固定）

S = 0.5 × RMSE(rain) + 0.3 × RMSE(dry_overcast) + 0.2 × RMSE(clear_dry)。

S 为 RMSE 的线性加权分数，单位 dB，越低越好；并非 sqrt(0.5×MSE雨+0.3×MSE阴+0.2×MSE晴)，也不是原样本频率下总体RMSE。不以天气样本占比再乘权重；缺一组不重分配权重、不填零。每个组的 RMSE 在原小时/站点小时上计算。这里的样本数是评分记录数，不当作独立传播事件数。

LOCAL 复用既有测试集687行的三组布尔标签。英国只在已有完整天气诊断的 original39 子集上评分；三组定义与LOCAL相同：总降水 p>=0.1mm 且雪水当量 s<0.1mm 为雨，p<0.1且s<0.1且总云量>=0.8为干燥阴天，p<0.1且s<0.1且总云量<=0.2为晴。其它与未知保留，不计三组分数。英国 tcc 取 t，tp/sf 取 t+1 的前一小时累计；m转mm；按站点和UTC键一一匹配，不插值。
