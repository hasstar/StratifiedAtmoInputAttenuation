# GBS与OpenSat外部验证准备

本地组合已完成数值评价与独立报告核验。外部实验使用新目录，原模型、原始测量与已存小时标签只读。外部少列模型另行拟合，属于同一方法在新数据上的验证，不冒充原156列网络的零样本迁移。

## 固定气象输入

前10项按Rev029自然RFE生存排名确定，不根据国外成绩选列：1hPa位势、1hPa纬向风、5hPa臭氧、650hPa纬向风、地面CAPE、地面上次后处理以来2m最高温、850hPa相对湿度、850hPa臭氧、5hPa纬向风、500hPa臭氧。云量、降水、降雪只用于天气诊断，不作为第11项等额外输入。

CDS将4类气压变量与5个气压面以笛卡尔请求下载，只有名单中8项气压字段进入模型，其他字段不加入输入。2项地面输入与3项天气诊断另取。官方请求、NetCDF字段/单位、有效UTC时刻和SHA256均保存在本轮`external`目录，完整字段QA前不训练。

ERA5小时总降水/降雪以有效时刻结束的上一小时为区间。接收小时`[h,h+1)`使用有效时刻`h+1`的降水/降雪，不对ERA5小时值再作日累计差分。请求补齐GBS文件日期缺口及最后一天之后的00 UTC，OpenSat补到2023-01-01 00 UTC。该约定依据[ECMWF累计变量说明](https://confluence.ecmwf.int/pages/viewpage.action?pageId=212460134)；瞬时与极值变量保留各自时刻定义。

## 日期与站点分区

GBS以原清单三站共同的399个文件日期固定分区：2004-02-18至2004-10-21的239日期训练；2004-10-22至2005-01-10的80日期验证；2005-01-11至2005-03-31的80日期测试。部分日历缺日期不填补。Chilbolton/Sparsholt用于训练与验证，Dundee完全不拟合，仅在测试报告；同时分别报告已见站与未见站。该范围不是全部1982个源文件的覆盖。

OpenSat以2022年8至10月训练、11月验证、12月测试。对215个原`sml_id`取SHA256排序，前43站只用于最终测试，172站用于训练/验证；测试按已见站/未见站分别报告。分区仅由元数据决定，不查看测试误差选择。

## 原生尺度与比较模型

GBS采用原生秒级相对晴空衰减，小时功率比定义及256秒连续块/IID对照保持清楚区分。OpenSat采用作者发布的分钟RSL，每小时60位置，主4分钟块相当于240秒，2/8分钟只做敏感性；分钟滞后为1/2/5/10/15/30分钟。不是256分钟，也不插值制造秒级真值。作者说明为1分钟平均，但未说明线性功率还是dB平均；结果按原生分钟观测的组合统计解释。

比较族固定BiLSTM、Transformer、MLP、SVR-RBF、XGBoost，统一seed17与Top10输入。正式训练协议在气象字段、可用小时和训练天气覆盖核验后，读取外部新测试成绩前另行冻结。验证只选择训练配置，测试不回调，不无限增加模型或挑种子。

## 下载与恢复

先完成两项小规模压力/地面预检，经独立字段、时间、单位QA后再启动77项正式月请求。`weather_download.py`使用已有CDS账户，不保存或输出密钥。每项先持久保存服务端请求ID，再等待下载；确认失败且同worker退出/OS锁释放后，以相同入口恢复原请求ID，不能重复提交排队任务。先查`weather_download.py status`及实际Python命令行/CPU、日志；任何匹配worker存活时只读检查。

所有下载写本轮新`external/weather`，旧ERA5/GBS/OpenSat不更改。服务端条款未接受或授权不足时，请求用户处理账户，不以代理来源替换官方字段。完整源/模型/预测/统计QA与中文报告通过后，才称三数据集组合实验完成。
