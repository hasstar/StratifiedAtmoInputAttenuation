# Three-source clear-sky attenuation label builder

Requires Python with NumPy, Pandas, PyArrow and h5py. `fetch_openmeteo_era5_proxy.py` also requires `requests`. The optional workspace-local official `cdsapi` client (`../_vendor_cdsapi/`) reads the existing user `.cdsapirc`; no token is copied into code, output or logs.

This frozen revision uses archived responses from `fetch_openmeteo_era5_proxy.py`: the Open-Meteo historical API with explicit `models=era5` at the 55 nearest 0.25° grid cells. `validate_weather_proxy.py` compared those responses with a directly obtained official CDS single-day sample; `compare_proxy_official_october.py` independently checks the available full October month. Open-Meteo rounds cloud and precipitation, so the proxy is **not** an exact replacement for official full-period ERA5. The direct CDS monthly requests are an optional follow-up, not an input to this version's labels. The one-day and October official files are retained only for proxy comparisons.

After all six proxy JSON batches and their comparison report exist, run `build_attenuation.py` once. The script never overwrites its `build_manifest.json` or any existing source-specific output, and may resume if complete local/CEDA tables were generated earlier. It writes one Parquet per source, plus the local full and high-coverage 10-level model tables. Run `validate_attenuation.py` afterward for an independent structural, source-hash and arithmetic audit. Both scripts are intentionally separate; validating the arithmetic does not establish physical clear-sky truth.

The OpenSat baseline is causal: a target hour can only use radar/ERA5-screened clear candidates from the same link in the preceding 15 days (or 30-day fallback), same UTC hour ±2 hours, excluding the target and all future signal. Require at least 20 candidate hours, taking their 75th percentile power. The local baseline is a single training-only screened candidate median after the existing gain calibration. CEDA retains its native attenuation. See the output `README.md` for scientific limitations and allowed claims.
