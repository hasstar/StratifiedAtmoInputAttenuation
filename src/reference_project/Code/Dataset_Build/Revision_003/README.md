# Revision_003：11 个气压层为主模型

本版本从已经独立验证的 `Outputs/Datasets/Revision_002` 派生，不重读或改写 ERA5、Run_011、H5 原始文件，也不覆盖 Revision_002。时间范围仍为北京时间 2025-09-30 至 2026-08-20；仅有实测的小时进入监督学习表，无实测小时不补标签。

## 正式输入和对照

| 角色 | 文件前缀 | 预测变量 |
| --- | --- | --- |
| 正式主模型 | `model_table_primary_p11_*` | 188 个单层 ERA5 产品变量 + 11 个气压层各 16 个变量，共 364 个候选变量 |
| 原论文对照 | `model_table_baseline_l5_*` | 同样的 188 个基础变量 + 原五个高度段各 16 个平均变量，共 268 个候选变量 |
| 0 气压层对照 | `model_table_baseline_p0_broad_*` | 188 个基础变量；其中包括整层／积分量，不能称为纯地表 |
| 严格近地表对照 | `model_table_baseline_surface_local_*` | 117 个近地表／局地变量 |

每种表都有 `all_measurements` 和 `high_coverage_95` 两个口径，以及 CSV 和 Parquet 两种格式。表内仅保留时间、冻结划分、唯一正式标签 `received_power_dbm` 和该表的 ERA5 预测变量；原表中的 `received_power_w` 是同一标签的精确变换，仅在 `measurement_hourly` 审计表保留，防止误当输入造成泄漏。`feature_sets.csv` 明确列出各表允许的预测变量；这些都是候选变量，不意味着最终模型必须全部使用。

## 11 层全组合消融

11 个气压层依次为 1000、925、850、700、650、500、300、200、30、5、1 hPa。`subset_catalog.csv` 逐行列出所有 `2^11 = 2048` 个组合；一个层位的 16 个变量必须整体保留或整体剔除。`subset_id` 的四位十六进制掩码以该顺序从低位到高位编码；`P11_07FF` 为全部 11 层，`P11_0000` 为没有气压层。`subset_counts.csv` 给出每个层数的理论及实际组合数；`feature_groups.csv` 把每个正式主模型预测变量映射到基础变量组或一个气压层。

主消融系列固定 188 个基础变量，因此 `P11_0000` 是“没有气压层”，**不是**严格近地表；严格近地表表单独保存。原五层是对 11 个配置气压层按原边界求等权平均，不等同于任选五个原始气压层。2048 个组合共用一张主模型表和可重建的列清单，不复制出 2048 份重复数据；**当前仅完成数据和实验清单，尚未训练这 2048 个模型，也没有其结果**。

所有组合须使用同一批合格小时、相同的时间划分与基础变量；预处理、特征筛选和调参只可在训练／验证数据内进行。主模型和原五层、0 气压层、严格近地表对照须事先指定；探索 2048 个组合后，不可用最终测试集反选“最佳”组合。1000 hPa 在部分时段没有有效视线交点，保留缺失；`missingness_by_level_split.csv` 记录各划分的缺失数。不可因为某一组合删除了 1000 hPa，就给它换一批更多的评估小时。

现有 `split_strict_24h` 顺时划分保留，隔离小时不能训练或测试。此前的事件均衡划分仍只是单独的补充提案，并未取代正式顺时测试。天气和信号事件标签不作为同刻模型输入。当前标签仍是接收功率；晴空参考功率口径未确定前不生成正式衰减标签。同期 ERA5 到同期功率属于估计／重构，不可直接称为提前预测。
